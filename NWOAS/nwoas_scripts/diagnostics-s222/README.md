# S222 — post-benchmark read-only Windows inventory

Run only after the benchmark has ended. Reports CPU metadata (not measured
frequency), logical core/RAM counts, device problem codes, network adapter
status and C: free space, followed by existing CPU and read checks. It changes
no driver, disk layout, power state or boot configuration. Device instance IDs,
MAC addresses and machine serial/identity properties are not selected.
Enumeration is not a USB transfer/hotplug test or proof that networking works.
